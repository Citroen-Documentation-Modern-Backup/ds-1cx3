B3EG34P0Dépose - repose : Électrovanne proportionnelle de direction assistée
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap09uc
[ 1] jeux de deux pince-durits 4153-T.
2. Dépose
Lever et caler le véhicule sur un pont à 2 colonnes.
Déposer :
  • Le pare-boue avant gauche (direction à gauche)
  • Le pare-boue avant droit (direction à droite)
Figure : b1bp2chc
Pincer le tuyau d’alimentation de la pompe de direction assistée, à l’aide de l’outil [ 1].
Figure : b3ep12tc
Déconnecter le connecteur (1).
Déposer :
  • Les vis (2)
  • L’électrovanne proportionnelle de direction assistée (3)
  • Le filtre (4) (dans le corps de valve)
3. Repose
Figure : b3ep12uc
IMPERATIF : Remplacer systématiquement les pièces suivantes : Le filtre (4), Les joints toriques (5).
Reposer :
  • Les joints toriques (5)
  • Le filtre (4)
  • L’électrovanne proportionnelle de direction assistée (3)
  • Les vis (2) Serrer à 0,3 m.daN
Reconnecter le connecteur (1).
Déposer l’outil [1].
Reposer :
  • Le pare-boue avant droit (direction à droite)
  • Le pare-boue avant gauche (direction à gauche)
moteur tournant, Manoeuvrer la direction dans chaque sens, de butée à butée.
Contrôler le niveau de fluide LDS (voir opération correspondante).
