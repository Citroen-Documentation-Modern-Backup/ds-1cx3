C4AG1RP0Dépose - repose : Capot moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Figure : c4ap1dmd
Désaccoupler le tuyau lave-vitre ( 6).
Dégrafer les stabilisateurs ( 4).
1.1. Capot seul
Desserrer les vis (3).
Déposer les vis (2).
1.2. Capot avec bras d’articulation
NOTA : Pour l’opération de dépose 2 opérateurs sont nécessaires.
Déposer les vis (5).
Déposer le capot (1).
2. Déshabillage
Figure : c4ap1dnd
Déposer :
  • Les gicleurs de lave-vitre ( 12)
  • Les cales latérales (11)
  • Le joint d’étanchéité (13)
  • Les butées caoutchouc (7)
  • Les agrafes (14)
  • La garniture de capot (10)
  • Les agrafes (8)
  • L’enjoliveur de capot (9)
3. Repose - Habillage
3.1. Pose et habillage du capot moteur
Procéder dans l’ordre inverse des opérations de dépose.
ATTENTION : Respecter les jeux et affleurements.
3.2. Pose de l’enjoliveur de capot
Nettoyer la zone d’application à l’aide d’un produit ( J1).
Amener la température de la zone d’application à 20°C.
Enlever le papier protecteur de l’enjoliveur de capot.
Présenter les tétons de l’enjoliveur de capot ( 9) en face des perçages de positionnement.
Appliquer l’enjoliveur sur le capot.
Appuyer fortement sur l’enjoliveur de capot du milieu vers les extrémités à l’aide d’un chiffon propre (5 secondes minimum).
Poser les agrafes ( 8) des extrémités vers le milieu de l’enjoliveur de capot.
