B1HGHHP0Dépose - repose : Injecteurs essence
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap2vvd
[ 1] raccord pour prise de pression carburant 4192-T.
2. Dépose
Débrancher la borne négative de la batterie.
NOTA : Cette opération doit être réalisée moteur froid.
Figure : b1bprqed
Raccorder l’outil [ 1] sur la valve de purge (1) du circuit d’alimentation carburant et recueillir l’essence dans un récipient.
ATTENTION : Lors du désaccouplement de la durit encliquetable ( 2), se protéger à l’aide d’un chiffon afin d’éviter toutes projections de carburant (pression résiduelle dans la rampe d’injection environ 1 bar).
Désaccoupler et obturer la durit ( 2).
Déconnecter les connecteurs (3).
Déposer :
  • Les vis (4)
  • L’ensemble rampe d’alimentation/injecteurs essence (5)
Figure : b1hp2and
Déposer :
  • Les agrafes (6) ; À l’aide d’un tournevis
  • Les injecteurs d’essence (7)
  • Les joints toriques (8)
3. Repose
IMPERATIF : Remplacer les joints toriques (8).
Reposer :
  • Les injecteurs d’essence ( 7)
  • Les agrafes (6)
  • L’ensemble rampe d’injection/injecteurs essence (5)
  • Les vis (4)
Serrer les vis (4) à 1 ± 0,1 m.daN.
Reconnecter les connecteurs (3).
Accoupler la durit ( 2).
Brancher la borne négative de la batterie.
